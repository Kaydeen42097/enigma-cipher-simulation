# Multi-Language Enigma Cipher Simulation

This project contains two implementations of a custom Enigma-inspired cipher machine, demonstrating cross-language software development in both Java and Python.

The goal of this project is to simulate a rotor-based encryption system and explore algorithm design in different programming paradigms.

I worked with a classmate on the python version it was for a csp project I redid it using the alphabet instead of numerical and in java junior year.

---

## Java Version

The Java implementation is a structured, object-oriented system that simulates a multi-rotor cipher machine using modular components such as rotors and reflectors.

### Features:
- Object-oriented architecture (Rotor, Reflector, Engine)
- Multi-rotor encryption pipeline
- Forward and reverse transformation logic
- Configurable rotor settings
- Alphabet-based encryption (A–Z)

---

## Python Version

The Python implementation is a more experimental, procedural version of the same cipher concept, focusing on algorithm behavior and numeric transformation logic.

### Features:
- Numeric cipher simulation (0–9 system)
- Procedural encryption pipeline
- Rotor shifting logic
- Reflector mapping system
- Test cases for validation

---

## Technologies

- Java (OOP implementation)
- Python (procedural implementation)

## Key Concepts Demonstrated

- Algorithm design and simulation
- Reversible transformations
- State-based systems
- Cross-language implementation of the same logic
- Cryptographic thinking (custom cipher design)

## Important Note

This is a custom Enigma-inspired simulation and not a historically accurate reproduction of the original Enigma machine.
