# Multi-Language Enigma Cipher Machine Simulation

This repository contains two distinct implementations of the historic WWII Enigma cipher machine, demonstrating cross-language fluency in both functional scripting and strict object-oriented programing.

* **Python Version**: A modular, 10-digit numerical simulation (0-9) focusing on algorithmic logic and structural data manipulation. Located in the `/python-version` directory.
* **Java Version**: A complete production-ready, object-oriented framework utilizing the full 26-letter alphabet (A-Z) with automated configuration string parsing. Located in the `/java-version` directory.
